# Вебинар: оценивание с Ustaz BilimAI Mektep

Интерактивная презентация для педагогов: ФО, СОР, СОЧ, промежуточное оценивание, проверка материалов, модерация и анализ результатов.

18 слайдов, 60 минут. Откройте index.html в браузере или используйте опубликованную страницу GitHub Pages.

Шаблоны запросов доступны в презентации через меню «Материалы» и в файле ustaz-assessment-prompts.txt.

Слайды содержат ссылки на использованные нормативные источники. Учебные примеры и записи о продвижении ученика являются иллюстративными.
