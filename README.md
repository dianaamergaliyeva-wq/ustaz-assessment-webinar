# Особенности разработки материалов для оценивания

Русская и казахская версии.

- index.html — RU; index-kk.html — ҚАЗ.
- Часть 1: 1–4 классы — 9 слайдов, 22 минуты.
- Часть 2: 5–11 классы — 17 слайдов, 47 минут.

Контакты и форма обратной связи — в конце второй части. feedback.html и feedback-kk.html открывают настроенную онлайн-форму Google на русском и казахском. Ссылка и QR-код находятся на заключительном слайде второй части. Ответы сохраняются в привязанную Google Таблицу; сбор имён и email отключён.

Кнопки RU / ҚАЗ сохраняют текущий номер слайда. Информация об авторе открывается кнопкой «Спикер».
