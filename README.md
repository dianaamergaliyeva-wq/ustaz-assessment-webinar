# Оценивание с Ustaz BilimAI Mektep

Презентация разделена на две самостоятельные части.

- Часть 1: 1–4 классы — учебные задания для 1 класса, ФО, промежуточное и итоговое оценивание для 2–4 классов; 13 слайдов, ориентир 40 минут.
- Часть 2: 5–11 классы — ФО, СОР, СОЧ, проверка, модерация, анализ результатов; 16 слайдов, ориентир 54 минуты.

Откройте index.html и выберите часть. В каждой части доступны программа, практика, заметки и собственные шаблоны запросов. Общие методические приёмы повторены там, где они нужны. Учебные примеры иллюстративные.
